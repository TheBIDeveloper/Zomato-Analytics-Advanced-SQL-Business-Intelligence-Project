# Zomato Analytics SQL Project

## 📌 Project Overview
This project analyzes Zomato-like food delivery data using **Microsoft SQL Server** to extract meaningful business insights related to customer behavior, restaurant performance, and revenue trends.


## 🎯 Business Problem
Zomato wants to answer key business questions such as:
- Which restaurants generate the highest revenue?
- How does customer ordering behavior change over time?
- Who are the repeat and high-value customers?
- What is the monthly revenue growth trend?
- Which cities and restaurants are driving growth?

As a data analyst, SQL Server is used to analyze transactional data and provide insights to business stakeholders.

## 🧠 Key Business Insights
- Repeat customers generate significantly higher revenue
- Few top restaurants contribute majority of total revenue
- Peak ordering hours occur during lunch and dinner time
- High-value customers fall within top 10% revenue bracket
- Certain cities show higher average order values
